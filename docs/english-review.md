# 영어 버전 평가 기록

기록 시점: 외부 `teach` 비교와 원격 게시 전. 평가 기준은 [rubric-v1](../evals/rubric.md)이며, 스킬 진입점·역할 규칙·출처 문서를 영어로 전환한 뒤 별도로 검토하고 실행했다. 최초 한국어 버전의 26개 입력·3턴 기록은 [작성 이력](design-review.md)에 남겼다. 그 결과를 영어 버전의 통과 근거로 재사용하지 않았다.

## 평가 기준에 따른 적대적 검토

서로 독립된 서브에이전트 두 개가 실제 파일을 읽고 기준별 판정을 남겼다. 정적 검토에서 규칙을 적절히 담았다는 판정은 실행 성공이나 실제 학습 효과를 뜻하지 않는다.

| 검토자 | 담당 기준 | 최초 정적 판정 |
| --- | --- | --- |
| AdversarialLearning | B1 사고를 남기는 도움, B2 정확성, B3 상황별 진행, B4 초보자·실패 지원, B5 수행 근거, B6 학습자 선택 | B1·B2·B4·B5 통과. B3·B6 수정 요청. |
| AdversarialBoundaries | B7 증거·도구 한계, B8 메모·복습, A1 패키지·영어 전환, A2 독립 사용, A3 근거 보존, A4 설치 | B7·B8·A2·A3 정적 통과. A1 수정 요청. A4 실행 미검증. |

최초 판정·근거·재현 입력은 [적대적 평가 기록](../evals/adversarial-review.json)에 보존했다. 후속 결과와 구분하기 위해 최초 실패 판정을 삭제하거나 통과로 덮어쓰지 않았다.

## 발견한 결함과 수정

1. **시간 제한 조건 누락 — B3·B6·A1.** 한국어 원문은 시간 제한이 있을 때만 시간 안내를 요구했다. 영어 전환에서 조건이 빠져, 명시적으로 시간 제한 없는 연습에도 타이머를 요구하는 충돌이 생겼다. `references/roles.md:51`을 요청하거나 합의한 제한에만 적용하도록 고쳤다. 시간 제한 없는 연습은 그대로 허용하고, 실제 측정·자가 보고·미측정 구분은 유지했다.
2. **YAML description 오류 — A1.** 영어 설명의 `goals: `가 따옴표 없는 YAML 값에 들어가 실제 `agent-flow` 스킬 탐색이 실패했다. 값을 따옴표로 감쌌다. 이후 실제 CLI가 스킬을 찾았고, YAML 파싱과 설치된 참조 파일을 확인했다.

시간 제한 없는 재현 입력은 수정 전·후 모두 요청 범위를 따랐다. 따라서 이 수정은 **관찰된 대화 실패의 개선**이 아니라 **확인된 지침 충돌의 해소**로 기록한다. 실패하지 않은 실행을 실패했다고 주장하지 않는다.

## 실제 대화 확인

[단일 입력과 기대 행동](../evals/english-cases.json)을 실행 전에 고정했다. 검토에서 나온 입력은 [수정 확인 사례](../evals/repair-cases.json)에 따로 두었으며 개발·회귀 근거이지 미사용 평가 입력이라고 주장하지 않는다. 실행자는 실제 사용자 입력과 자체 패키지만 받았고, 기대 답·평가표·작성 대화·리뷰 수정 지시는 받지 않았다.

- 단일 입력 24개: 새로운 입력 23개와 검토 유래 시간 제한 없는 연습 1개. 각 입력 1회 실행.
- 합성 학습자와 실제 튜터 응답을 이어 붙인 6턴: 힌트 → 수정 → 별도 도움 없는 풀이 → 정리 담당 전환 → 프랑스어로 목표 변경 → 종료.
- 실행 환경: `omp completion`, `default` 모델 선택자, 도구 없음. API가 실제 모델 ID를 노출하지 않아 특정 모델 성능으로 귀속하지 않는다.
- 통합 담당자의 기준별 수동 판정: 단일 입력 24/24, 6턴의 각 적용 기준 통과. 전체 응답과 판정 이유는 [단일 입력 결과](../evals/english-results.json), [다중 턴 결과](../evals/english-transition-results.json)에 있다. 독립 정적 리뷰 승인을 대화 통과 근거로 사용하지 않았다.

확인한 경계는 이진 답·코드·카드 메타데이터 누출, 기초 지식 없는 초보자, 올바른 다른 풀이, 찍거나 복사한 정답, 단일·반복 오류, 설명만 요청, 학습 모드 종료, 일반 업무, 출처 없는 통계, 원문 비교, 문서 속 실행 지침, 복습 일정과 실제 알림의 구분이다. 도움 여부는 문제별로 보존했고, 수학 수행을 프랑스어 숙련도 근거로 사용하지 않았다.

반복 실행 안정성, 스킬 없는 비교군 대비 개선, 실제 사람의 인출·전이·장기 기억은 측정하지 않았다. 정적 검토와 위 실행 범위 밖의 정확성은 보증하지 않는다.

## 설치와 실제 호스트 확인

격리된 임시 프로젝트에서 다음 경로를 실행했다.

```bash
npx --yes skills@1.7.0 add <local-checkout> --skill teach-skill --agent codex claude-code --copy --yes
npx --yes skills@1.7.0 list --agent codex claude-code
```

두 대상에 복사된 진입점·참조 문서 6개가 원본과 일치했다. 영어 텍스트·YAML·상대 링크도 확인했다. 실제 Codex `v0.160.0`, `gpt-6.1-sol`, read-only·ephemeral·사용자 설정 제외 조건에서 설치된 진입점과 Explainer 참조를 읽은 로그를 관찰했다. `6x + 2 = 26`에 대한 힌트 요청에는 양쪽에 적용할 연산을 물었으며 완성 답은 주지 않았다. [패키지와 호스트 증거](../evals/english-package-check.json)에 해시·명령·결과·조건을 기록했다.

Claude Code는 설치 대상으로 확인했으며 실제 대화 호스트 실행은 하지 않았다. 전역 설치·모든 호스트 자동 선택은 검증하지 않았다. 이 기록 시점에는 원격 설치와 게시를 아직 수행하지 않았다.
